# obrobka-zdjec
## Opis
Program w Java służący do przekształcania z i do własnego formatu zdjęć. Format ten wyznacza się możliwością dostosowania kompresji, który znacznie wpływa na rozmiar pliku.

## Funkcje
- Przekształcanie plików z/do formatu własnego
- Przekształcanie plików na .png, .jpg, etc.
- Pełna możliwość dostosowania kompresji
